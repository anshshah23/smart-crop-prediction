5.2.2 SMOTE Theoretical Foundation
----------------------------------
SMOTE generates synthetic samples through k-nearest neighbor interpolation.

ALGORITHM (Equation 5.1):
```
For each sample x_i in minority class:
    1. Find k nearest neighbors (default k=5)
    2. Randomly select one neighbor x_neighbor
    3. Generate synthetic sample:
       x_synthetic = x_i + λ × (x_neighbor - x_i)
       where λ ~ Uniform(0, 1)
    4. Repeat to create desired number of samples
```

MATHEMATICAL REPRESENTATION:
```
x_new = x_original + random(0,1) × (x_neighbor - x_original)
```

Where:
- x_new = newly generated synthetic sample
- x_original = existing real sample
- x_neighbor = one of k nearest neighbors
- random(0,1) = random value between 0 and 1

VISUAL CONCEPT (Figure 5.1):
```
    Real Sample A ●─────────●─────────● Real Sample B
                        ↑
                  Synthetic Sample
              (Interpolated between A and B)
```

SMOTE PROPERTIES:
1. ✅ Preserves statistical distributions
2. ✅ Creates diverse samples (not copies)
3. ✅ Maintains feature relationships
4. ✅ No training required
5. ✅ Deterministic with random_state

CORE FUNCTION (Listing 5.1):
```python
def generate_synthetic_data_smote(data, scaler, n_samples, feature_names):
    """
    Generate synthetic data using SMOTE k-NN interpolation.
    
    Args:
        data: Normalized data array
        scaler: Scaler for inverse transformation
        n_samples: Number of synthetic samples to generate
        feature_names: List of feature names
    
    Returns:
        Synthetic data in original scale
    """
    print(f"🚀 Generating {n_samples} synthetic samples using SMOTE...")
    print(f"   Dataset size: {len(data)} real samples")
    
    # Create dummy labels (all same class)
    y_dummy = np.zeros(len(data))
    
    # Calculate total needed samples
    total_needed = len(data) + n_samples
    
    # Adjust k_neighbors based on dataset size
    k_neighbors = min(5, len(data) - 1)
    
    print(f"   K-neighbors: {k_neighbors}")
    print(f"   Target total: {total_needed} samples")
    
    # Initialize SMOTE
    smote = SMOTE(
        sampling_strategy={0: total_needed},
        k_neighbors=k_neighbors,
        random_state=42
    )
    
    try:
        # Generate synthetic samples
        X_resampled, _ = smote.fit_resample(data, y_dummy)
        
        # Extract only new samples
        synthetic_data_normalized = X_resampled[len(data):][:n_samples]
        
        # Inverse transform to original scale
        synthetic_data = scaler.inverse_transform(synthetic_data_normalized)
        
        print(f"✅ Successfully generated {len(synthetic_data)} samples")
        print(f"   Method: SMOTE k-NN interpolation")
        print(f"   Quality: High (interpolated from real data)")
        
        return synthetic_data
        
    except Exception as e:
        # Fallback to noise augmentation if SMOTE fails
        print(f"❌ Error: {e}")
        print(f"   Falling back to noise-based augmentation...")
        # [Fallback code...]
```

FUNCTION PARAMETERS (Table 5.7):
Parameter      | Type          | Description
---------------|---------------|----------------------------------------
data           | numpy.ndarray | Normalized input data
scaler         | MinMaxScaler  | Fitted scaler for inverse transform
n_samples      | int           | Number of synthetic samples to create
feature_names  | list          | Names of features (for documentation)
RETURNS        | numpy.ndarray | Synthetic data in original scale

SMOTE CONFIGURATION:
- sampling_strategy: {0: total_needed} - Generate to reach target total
- k_neighbors: 5 (or less if dataset smaller)
- random_state: 42 (reproducibility)
