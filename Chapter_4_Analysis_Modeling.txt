FUNCTIONAL MODULES

Module 1: Data Management
├── Function: load_dataset()
│   Input: CSV file path
│   Output: Pandas DataFrame
│   Processing: Read, validate structure
│
├── Function: filter_data(crop, state)
│   Input: Crop name, State name
│   Output: Filtered DataFrame
│   Processing: Boolean indexing
│
└── Function: merge_weather(crop_df, weather_df)
    Input: Two DataFrames
    Output: Combined DataFrame
    Processing: Join on date/location

Module 2: Weather Integration
├── Function: fetch_weather_api(lat, lon, days)
│   Input: Coordinates, duration
│   Output: Weather DataFrame
│   API: Open-Meteo Archive
│   Parameters: temp, rainfall, soil
│
└── Function: parse_weather_json(response)
    Input: JSON response
    Output: Structured DataFrame
    Processing: Extract daily values

Module 3: Synthetic Data Generation
├── Function: apply_smote(X, y)
│   Input: Features, Labels
│   Output: Augmented X, y
│   Algorithm: k-NN interpolation (k=5)
│   Result: 5x data multiplication
│
└── Function: validate_synthetic(df)
    Input: Synthetic DataFrame
    Output: Quality metrics
    Checks: NaN count, distribution, outliers

Module 4: Machine Learning
├── Function: train_model(X_train, y_train)
│   Input: Training data
│   Output: Trained RF model
│   Parameters: n_estimators=120, max_depth=10
│
├── Function: predict_yield(model, X_test)
│   Input: Model, Test features
│   Output: Predictions (0/1/2)
│   Classes: Low/Medium/High
│
└── Function: evaluate_model(y_true, y_pred)
    Input: Actual, Predicted
    Output: Accuracy, Precision, Recall, F1
    Visualization: Confusion matrix

Module 5: Reporting
└── Function: generate_report(results)
    Input: Model metrics
    Output: Classification report
    Format: Precision/Recall/F1 per class
