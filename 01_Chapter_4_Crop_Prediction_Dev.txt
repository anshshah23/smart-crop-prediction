4.4.1 Historical Weather Data Collection (Cell [Ch4.17])
-------------------------------------------------------
A critical innovation in this project is the integration of real-time weather
data from the Open-Meteo Archive API. This provides environmental context for
crop yield predictions.

API DETAILS:
- Service: Open-Meteo Archive API (https://archive-api.open-meteo.com)
- Data Type: Historical weather and soil conditions
- Time Period: Last 90 days
- Sampling Frequency: 3 readings per day (6 AM, 12 PM, 6 PM)

FUNCTION IMPLEMENTATION (Listing 4.3):
Cell Reference: Cell 17 (Lines 190-371)

```python
def fetch_historical_weather_data(lat, lon, days=90):
    """
    Fetch historical weather and soil data for the last N days.
    Returns data for 3 times per day: morning, midday, evening
    """
    end_date = datetime.now()
    start_date = end_date - timedelta(days=days)
    
    url = f"https://archive-api.open-meteo.com/v1/archive?..."
    # API parameters include:
    # - latitude, longitude
    # - start_date, end_date
    # - hourly: temperature, precipitation, soil data
    # - daily: max/min temp, precipitation sum, sunshine
```

GEOGRAPHIC COORDINATES:
- Location: Lucknow, Uttar Pradesh
- Latitude: 26.8467° N
- Longitude: 80.9462° E
- Rationale: Central location for Bajra-growing region

4.4.2 Weather Features Collected
--------------------------------
HOURLY READINGS (3 times per day):
1. temperature_2m - Air temperature at 2m height
2. precipitation - Hourly precipitation amount
3. soil_temperature_0cm - Surface soil temperature
4. soil_temperature_6cm - Subsurface soil temperature (6cm depth)
5. soil_moisture_0_to_1cm - Topsoil moisture content
6. soil_moisture_3_to_9cm - Deeper soil moisture level

DAILY AGGREGATES:
1. temperature_2m_max - Daily maximum temperature
2. temperature_2m_min - Daily minimum temperature
3. precipitation_sum - Total daily precipitation
4. sunshine_duration - Daily sunshine hours

Table 4.5: Weather Feature Specifications

Feature                  | Unit       | Measurement Type | Frequency
------------------------|------------|------------------|----------
temperature             | °C         | Hourly           | 3x daily
precipitation           | mm         | Hourly           | 3x daily
soil_temp_0cm           | °C         | Hourly           | 3x daily
soil_temp_6cm           | °C         | Hourly           | 3x daily
soil_moisture_0_1cm     | m³/m³      | Hourly           | 3x daily
soil_moisture_3_9cm     | m³/m³      | Hourly           | 3x daily
temp_max_daily          | °C         | Daily aggregate  | 1x daily
temp_min_daily          | °C         | Daily aggregate  | 1x daily
precipitation_sum_daily | mm         | Daily aggregate  | 1x daily
sunshine_duration_daily | seconds    | Daily aggregate  | 1x daily

4.5.7 Model Evaluation Metrics
----------------------------------------------
PERFORMANCE METRICS:
1. Precision = TP / (TP + FP) - Prediction accuracy
2. Recall = TP / (TP + FN) - Coverage of actual cases
3. F1-Score = 2 × (Precision × Recall) / (Precision + Recall)
4. Accuracy = (TP + TN) / Total - Overall correctness
