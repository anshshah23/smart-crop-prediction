8.2.2 API Endpoint Design
-------------------------
PROPOSED API STRUCTURE:

1. POST /api/predict
   Request:
   ```json
   {
     "district": "Lucknow",
     "season": "Kharif",
     "area": 1000,
     "use_live_weather": true
   }
   ```
   Response:
   ```json
   {
     "prediction": "High",
     "confidence": {
       "Low": 0.15,
       "Medium": 0.25,
       "High": 0.60
     },
     "weather_conditions": {
       "temp_max": 32.1,
       "temp_min": 18.5,
       "rainfall": 45.2,
       "soil_moisture": 0.35
     },
     "recommendation": "Optimal conditions for high yield. Ensure adequate irrigation."
   }
   ```

2. GET /api/districts
   Response: List of available districts

3. GET /api/weather/{district}
   Response: Current weather data for district

4. POST /api/retrain
   Trigger model retraining with new data

ESTIMATED TIME: 2-3 weeks
PRIORITY: MEDIUM
